## METAPOST+LaTeX+Biber

`cd mppics/`<br>
`mpost pic`<br>
`cd ..`<br>
`pdflatex birkhoff-ru`<br>
`biber birkhoff-ru`<br>
`pdflatex birkhoff-ru`<br>
`pdflatex birkhoff-en`<br>
`biber birkhoff-en`<br>
`pdflatex birkhoff-en`<br>
